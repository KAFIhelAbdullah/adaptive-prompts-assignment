
# Adaptive Prompts for Personalized Learning

This repository contains a completed assignment for the topic **Adaptive Prompts for Personalized Learning**, focused on creating a dynamic, personalized learning experience using adaptive prompt engineering.

## 📘 Assignment Overview

- **Learning Domain**: High School Algebra – Solving Linear Equations
- **Objective**: To design and implement an adaptive prompt system that adjusts dynamically based on learner responses, proficiency, preferences, and progress.
- **Approach**:
  - Multi-level prompt design (novice, intermediate, advanced)
  - Personalized adaptations (e.g., step-by-step help, visuals, challenge problems)
  - Simplified Python logic for dynamic adaptation
  - Strategies for tracking progress and tailoring learning

## 📄 Files Included

- `Full_Adaptive_Prompt_Assignment.docx`: The complete write-up of the assignment, including prompt designs, adaptation strategy, algorithm, and evaluation.
